On a history of its own, and both halves of that matter.

Shorter, because refuting costs what accepting does not: to accept,
the checker finds one linearization and stops; to refute, it must
exhaust the space and show there is none. On the whole depth-8
history above, that ran the machine out of memory and the control
was killed partway through — neither a pass nor a failure, and an
arm that reports nothing cannot make the other arm evidence.

A *history*, not a prefix of the one above, because a prefix of a
concurrent history is not a history. At depth 8 a read can return a
value written by an operation invoked after it, so the write sits
later in a file ordered by invocation; cut the file and the read
survives while the write it observed does not. The checker then
rejects — for a reason that has nothing to do with the mutation, and
the arm reports success while demonstrating nothing. That was tried.
